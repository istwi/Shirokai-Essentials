# Essentials 0.3.3-guard.1 — Ender Chest

Correção da expansão indevida da permissão de Ender Chest pelo LuckPerms.

Instale uma única variante com o servidor parado: `shirokai-essentials-0.3.3-guard.1.jar` ou `shirokai-essentials-0.3.3-guard.1-zorykai-visual.jar`. Remova o JAR anterior e preserve as configurações existentes.

A permissão `shirokai.essentials.enderchest` continua válida para o próprio baú. Para terceiros, conceda também `shirokai.essentials.enderchest.others` à administração. Wildcards administrativos e fallback OP configurado são preservados.

Build, 51 testes JUnit e 17 verificações no servidor com LuckPerms real e jogadores simulados aprovados. Veja [relatório](../../docs/ENDERCHEST-0.3.3-guard.1.md). Não foram criadas tags ou alteradas releases existentes.
