# Essentials 0.4.0-guard.1

- `/craft` e `/bancada`: bancada virtual.
- `/bigorna`: bigorna virtual com custo normal de níveis.
- `/rebolo`: rebolo virtual.
- `/reparar`: repara o item na mão.
- `/luz`: liga/desliga visão noturna.
- `/esquentar`: funde a pilha na mão com recarga persistida de 5 minutos.

Nomes ingleses existentes e o hotfix do Ender Chest foram preservados. [Permissões e configuração](../../docs/UTILIDADES-0.4.0-guard.1.md).

Com o servidor parado, instale somente uma variante e retire o JAR anterior. Preserve configurações e mundo. Ative o módulo utilities e conceda os nós desejados aos grupos. A atualização adiciona os aliases e campos novos com backup; alterações na árvore de comandos exigem reinício.

Build, 55 testes automatizados e 40 verificações em servidor real com jogadores simulados aprovados. Somente uma branch nova foi enviada; não houve deploy ou alteração das releases anteriores.
