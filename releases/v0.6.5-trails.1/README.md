# Zorykai Essentials 0.6.5-trails.1

Versão server-side com rastro mais largo, intervalo próprio e densidade proporcional ao tamanho visual das partículas.

- Água recebe densidade `3x` por usar gotas pequenas.
- Elétrico, fantasma, neve, magia e encantado recebem `2x`.
- Novos estilos: neve, corações, magia, encantado, nuvem e cerejeira.
- Não requer mod no cliente.
- Não inclui asas nem modelos 3D.

Use o JAR `zorykai-visual` para os textos visuais Zorykai.
