# Zorykai Essentials 0.6.6-continuous-trails.1

O rastro agora interpola partículas entre a posição anterior e a atual, preenchendo o caminho continuamente sem formar blocos separados.

- Mantém densidade proporcional por estilo.
- Mantém o intervalo configurável de emissão.
- Funciona andando, correndo, agachado e mudando de direção.
- Somente servidor; nenhum mod cliente é necessário.

Use o JAR `zorykai-visual` para os textos visuais Zorykai.
