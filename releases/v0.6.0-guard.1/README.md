# Essentials 0.6.0-guard.1 — Cosméticos

Use **apenas um** dos JARs desta pasta. A variante `zorykai-visual` mantém a marca Zorykai nos textos e os mesmos IDs, configurações e funcionalidades.

Minecraft 1.21.1, Fabric, Java 21 e Fabric API. Atualize substituindo o JAR anterior com o servidor desligado; preserve as configurações e dados existentes.

Comando principal: `/cosmeticos`. Para liberar acesso: `shirokai.essentials.cosmetics.use` e os IDs das opções desejadas. Acesso não é liberado automaticamente para jogadores comuns.

[Guia completo e limitações](../../docs/cosmetics/README.md) · [Evidências dos testes](../../docs/cosmetics/results.json).

Menus por categoria; nick, rastros, auras, pegadas, coroas, asas, círculos, teleportes, entrada, vitórias PvP, celebrações de raid, sazonais, coleções e opção de desativar. Sem mod adicional no cliente ou pacote de recursos.

Asas são partículas, não permitem voar. A cor do nick pode aparecer na lista de jogadores e não substitui equipes de rank existentes. Vitória em batalha Pokémon comum não está integrada. Aparência ainda precisa de revisão em cliente gráfico.
