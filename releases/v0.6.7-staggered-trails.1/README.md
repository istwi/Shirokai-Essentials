# Zorykai Essentials 0.6.7-staggered-trails.1

O lote do rastro agora é distribuído ao longo dos ticks. As partículas nascem e desaparecem em momentos diferentes, removendo os cortes visuais causados por lotes sincronizados.

- Interpolação espacial entre posições.
- Emissão temporal escalonada.
- Mesma proporção total de densidade por estilo.
- Proteção contra linhas após teleporte ou troca de dimensão.
- Somente servidor; nenhum mod cliente é necessário.

Use o JAR `zorykai-visual` para os textos visuais Zorykai.
