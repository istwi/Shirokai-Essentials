# Essentials 0.6.3-simple.1 — cosméticos simples

Use apenas um JAR de Essentials. A variante `zorykai-visual` mantém os textos visuais Zorykai e usa os mesmos IDs técnicos.

Esta versão parte do comportamento de cosméticos 0.6.0 e conserva o intervalo original de 5 ticks. O menu contém somente cor do nick, rastros no chão, aura, entrada, vitória e raid. Não instale o complemento cliente de asas 3D.

Substitua o JAR anterior com o servidor desligado. Preserve `config` e a pasta do mundo. Escolhas antigas de categorias removidas permanecem armazenadas, mas não aparecem nem geram efeitos.
