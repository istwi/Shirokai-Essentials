# Zorykai Essentials 0.6.9-speed-scale.1

Corrige a escala do comando `/speed`:

- `/speed 1` restaura caminhada normal (`0,10`).
- `/speed 1` durante o voo mantém voo normal (`0,05`).
- A velocidade de animação dos cosméticos continua sendo configurada apenas no menu `/cosmeticos`.

Inclui também todas as correções do rastro contínuo com ponto sob os pés. Use o JAR `zorykai-visual` para os textos visuais Zorykai.
