# Zorykai Essentials 0.6.4-personalization.1

Versão server-side com os seis cosméticos simples e personalização segura de velocidade, tamanho, densidade e direção.

- Use o JAR `zorykai-visual` para os textos visuais Zorykai.
- Minecraft 1.21.1, Fabric e Java 21.
- Não requer mod no cliente.
- Mantém o intervalo original de 5 ticks.
- Não inclui asas, modelos 3D nem as categorias removidas.

Permissão adicional: `shirokai.essentials.cosmetics.customize`.
